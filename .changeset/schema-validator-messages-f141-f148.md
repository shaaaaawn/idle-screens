Validator messages and the loop-seam advisory, from the Screen Test cold read and Spin's reports. Nothing the validator accepts or refuses changes.

- **A shape error echoes the value and the fix (F142).** A number where a `[min,max]` range belongs now reads `… — got 0.018; write [0.018, 0.018]`, a range where one number belongs reads `… — got [0.0012, 0.002]; a streak's `width` is one number`, and `region.x: {min, max}` reads `… — got {min, max}; write [0.2, 0.8]`. A reversed range says which number goes first, and a value that is out of bounds is echoed without a suggested fix. One helper builds these lines for every range and scalar field. It changes only the wording and never coerces a value. A path stroke's `width`, which had no range branch, is covered too.
- **A missing colour is reported as missing (F141).** A sprite with no `color` and no `colors` now gets "`color` is required (or a `colors` palette)" instead of "must be a hex colour like #0a3a52". For a polygon the message adds that parts without a colour inherit it, and that a gradient or stroke does not stand in for it. A path `stroke` with no `color` says the colour is required on a stroke. A value that is present but malformed keeps the format error. FORMAT.md now says that `parts` and `gradient` still need an entity `color` or `colors`.
- **Unknown keys in nested paint objects warn (F148, X761).** An unknown key inside a sprite's or a part's `stroke`, a path `gradient` (checked per type, so a radial's `from` warns), a gradient stop, a background stop, `band` or a gradient's `drift` now raises the same non-blocking `unknown-property` warning that `stroke.draw.zzz` already did. `ignoredPropertyPaths` lists these keys too. No shipped example or fixture warns.
- **`loop-seam` leaves out spin, rock, pulse and grow (F145, X725, X823).** These parts run on scene time and change smoothly, so nothing jumps when a looping timeline wraps, and advice like "make the lap a multiple of 1800000 ms" could not be followed. The advisory now judges only the periodic parts that remain (path laps, orbits, emit, cycle, caret, background drift), and its message names only those parts. `scenePeriod` still reports the full period. Its result has a new `kinds` array, and both `scenePeriod` and `periodWithoutTimeline` take an optional set of part kinds to skip.
