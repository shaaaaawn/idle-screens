# @idle-screens/capabilities

Device and capability detection plus saver eligibility tiering for idle-screens. Pure decision logic (Node-testable) plus a thin browser detector.

It has no runtime dependencies. `@idle-screens/saver-metaquarium` uses it to choose a rendering tier for the device it runs on.

See the [idle-screens repository](https://github.com/shaaaaawn/idle-screens) for full documentation.
